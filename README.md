# Java Day 53 - Quiz Management System

## Description
A console-based quiz application developed using Java. It displays multiple-choice questions, checks answers, calculates scores and saves participant results.

## Features
- Start a multiple-choice quiz
- Display four options for each question
- Check correct and incorrect answers
- Calculate score and percentage
- Save quiz results in a text file
- View previous quiz results

## Files
- `Main.java` - Main Java program
- `quiz_results.txt` - Generated quiz result history

## Requirements
- Java JDK

## How to Compile
```bash
javac Main.java
```

## How to Run
```bash
java Main
```
